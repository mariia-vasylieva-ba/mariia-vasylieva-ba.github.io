A Personal AI Operating System

I set up one shared "brain" that both ChatGPT and Claude read and write. On top of it I built two tools: a job search agent that tailors and reviews my applications, and a Telegram bot that handles household reminders. I ran it the way I run client work. Pain points first, then requirements, a build or buy decision, and a new version each time the old one failed.

15 min for two tailored, scored and reviewed applications. One application used to take about an hour.
10 applications in the first week with the agent, well above my previous pace
£38 a month running cost: subscriptions I already had, plus about 9 cents per GPT review

The problem

I use ChatGPT and Claude every day. Each one only knew what I had told it in that chat, so I kept copying the same context from one to the other.

At the same time my job search had slowed down. Tailoring one CV took at least 30 minutes, and a full application took about an hour. Researching each company was emotionally draining, and my application pace dropped. A smaller, constant irritation sat alongside it: the same household reminders for my husband and me, over and over.

The trigger was a free TechTalk community webinar, where Laurie Wang showed the idea of one shared brain for all your AI tools. I decided to try it, and to treat it like a small product.

I treated my own admin as a client brief.

Where things stood

  • Context lived inside separate chat histories. Switching between ChatGPT and Claude meant copying and explaining everything again.
  • Every application was manual: reading the role, tailoring the CV, writing a cover letter and researching the company. About an hour each.
  • Household reminders were repeated by hand.

Requirements

  • Works with any AI assistant. ChatGPT and Claude now, others later.
  • The same context on desktop and on phone.
  • Not locked inside one tool. The files are mine.
  • No invented experience in any CV or cover letter. Facts come from one place only.
  • An independent second reviewer for anything that goes to an employer.
  • I stay in control. I review and submit every application myself.
  • Reminders arrive with a clear way to mark them done, and keep asking until someone does.

Solution design

1. The brain

An Obsidian vault stored in a private GitHub repo. Both assistants read and write it through their GitHub connectors, so whichever one I open, on desktop or on phone, starts from the same files.

  • 00 Brain holds who I am and what matters right now: ABOUT_ME, CURRENT_CONTEXT, GOALS, HOW_I_WORK and WEEKLY_PLAN.
  • 10 Projects has one folder per project, such as Bathroom, Job Search, Junior and Garden. Each uses the same files: PROJECT, NEXT, DECISIONS, INVENTORY and LOG.
  • 20 Workflows describes routines. The morning update reads my calendar, email and CURRENT_CONTEXT and gives me a short daily plan. The cross-check lets ChatGPT and Claude review each other's work through shared files, without an API. I used it for my bathroom renovation: the inventory, the decisions and the next steps.

To fill it, I let ChatGPT interview me with the questions from Laurie's guide. Claude then reviewed and restructured the result. These days I mostly talk to both assistants by voice.

2. The Job Search Agent

  • Adjusted for UK job boards and UK norms.
  • Scans my job-alert emails twice a week and shows a top 5 shortlist. LinkedIn roles I paste in by hand, and they get scored too.
  • The /apply command drafts a tailored CV and cover letter. GPT reviews them as a second reviewer, through GitHub Actions and the OpenAI API. Claude then applies the fixes.
  • Every CV fact comes from one profile file, so nothing can be invented along the way.
  • Every portfolio link in a CV carries a tracking label for that application, so I can see which application led to a visit.
  • A tracker CSV keeps the history. I always review and submit myself.

3. Junior, the reminder bot

I tell any assistant in plain words, for example "remind my husband on Friday at 6pm to order cat food". The reminder arrives in Telegram with a Done button. If nobody taps it, Junior asks again, up to six times. When someone taps it, I get a confirmation. It works for my own reminders too.

Build or buy

The brain: I skipped a tool comparison on purpose. The question was whether a shared brain was worth having at all, and I wanted an answer fast. Obsidian and GitHub were enough to test that, and setup took one working day.

The Job Search Agent: I had a design ready. A fit-scoring agent, a CV-tailoring agent, an independent reviewer, strict checks against invented experience, and two AIs checking each other. Before building it, I looked for existing work and found ai-job-search by Mads Lorentzen, an MIT-licensed project built for the Danish market. I adapted it in a private repo instead of starting from scratch, and kept the original as upstream, as its README recommends. The author commented positively on my LinkedIn post about it.

Iterations and failures

Junior took three versions to become reliable.

  1. v0. A Python bot using FastAPI and ngrok. It only worked while my laptop was on.
  2. v1. GitHub Actions on a schedule. I planned about 30 runs a day. In practice it ran three or four times, because scheduled runs were skipped. It also lost a Done button press.
  3. v2. Cloudflare Workers. It wakes every 15 minutes from 7:00 to 22:45 London time, handles the Done button instantly through a webhook, and keeps its state in Cloudflare KV. Reminders live in REMINDERS.yaml in the brain repo. A push runs the tests and deploys through GitHub Actions. The tests replay the schedule on a fake clock, including the clock change and a downtime alert.

Planned: about 30 runs a day. Actual: three or four.

What changed

  • Two applications tailored, scored and reviewed in 15 minutes. One application used to take about an hour.
  • 10 applications in the first week, well above my previous pace, with much less mental load.
  • Both assistants start from the same context on desktop and phone. No more copying between them.
  • Reminders now come with a Done button and a confirmation instead of being repeated by hand. Junior uses about 100 of the 100,000 requests a day on Cloudflare's free tier.
  • I wrote about the build in four LinkedIn posts. The Job Search Agent post got the most engagement.

Cost

About £38 a month, all of it subscriptions I already had. On top of that, each GPT review costs about 9 cents. Junior runs on Cloudflare's free tier.

Risks and limitations

  • Security. The repo is private and holds no passwords or financial details. I accepted the remaining risk consciously for the experiment, and a proper security review is in my backlog.
  • AI mistakes. Drafts can be wrong, which is why facts come from one profile file, a second AI reviews every draft, and nothing goes out until I have read it.
  • Manual steps. LinkedIn roles still have to be pasted in by hand.
  • Timing. Junior only checks every 15 minutes, and only between 7:00 and 22:45.
  • Sample size. These results come from one user, me, over a short period.

What I'd do next

  • Run the security review that is waiting in my backlog.
  • [to confirm] Use the tracking labels and the tracker CSV to measure outcomes, not just pace: which applications lead to portfolio visits and replies.
  • [to confirm] Connect a third assistant to the brain, since it was designed to work with any AI.
